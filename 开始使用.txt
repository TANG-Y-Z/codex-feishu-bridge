Codex 手机助手 · v0.1.1 Windows / macOS 文字版

收到压缩包后，请先“全部解压”，不要在压缩包内直接运行。
双击「先读我.html」，用浏览器查看完整设置说明，离线也能打开。

你需要自己的 Codex 桌面应用、Node.js 24、飞书账号和飞书自建机器人。
不用建群，不需要微信开发者工具，不需要小程序。
本版不含 /预览 和 /网页截图。

Mac 用户：请先打开「Mac-开始使用.txt」，使用 .command 脚本；.cmd 仅供 Windows。
Mac 实机连接尚待验证，请先通过 npm run doctor，再测试手机收发。

Windows 顺序：
1. 安装 Node.js，双击「1-安装依赖.cmd」。
2. 创建自己的飞书应用，开通机器人和两项消息权限。
3. 双击「2-填写配置.cmd」，在 .env 填自己的 App ID、App Secret 并保存。
   同时打开的 bridge.config.json 是可选路径配置，通常三项留空即可。
4. 在 Codex 打开本目录，让它运行 npm run setup:codex 和 npm run doctor。
5. 双击「3-启动机器人.cmd」，保持窗口打开。
6. 长连接建立后，回飞书后台保存事件配置、添加接收消息事件、发布。
7. 在手机私聊机器人，发 /绑定 加启动窗口中的绑定码，然后 /状态、/会话、/切换 编号。

机器人只接受你的私聊。只想暂时不收通知，用 /静音；恢复用 /通知。
彻底退出用 /关闭，重新开启需要回到电脑双击启动文件。

请把密钥只填进自己电脑的 .env，不要发给朋友或粘贴给 AI。
分享包不含原作者的密钥、聊天、绑定数据或电脑连接配置。
你运行后生成的 .env、bridge.config.json、bridge.local.json、.data 都是私人数据，不能再打包发给别人。
要再次分享，请转发原始 ZIP。

兼容性：Codex 接入依赖桌面自带的内部工具，并非官方稳定 API；安装时需通过 doctor。
